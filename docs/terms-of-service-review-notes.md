# 선녀 사주 이용약관 초안 검토 메모

작성 기준일: 2026-09-10

대상 문서: [이용약관 전문 초안](./terms-of-service-draft.md)

이 문서는 내부 검토용이며 이용약관 페이지의 본문에 포함하지 않는다. 초안은 게시·시행하거나 운영 정책으로 확정한 상태가 아니다. 실제 판매 방식과 제공 기능을 확정한 후 해당 부분을 맞추고 법률 검토를 거쳐 게시한다.

- 첨부 사업자등록증의 법인명·대표자·등록번호를 대조하고 사업장 주소를 반영했다: **서울특별시 동대문구 왕산로 200, 가동 1204호(전농동, 청량리역 롯데캐슬 스카이-엘65 섹션오피스)**. 등록증의 개업일은 약관 시행일로 사용하지 않았다.

- 카탈로그의 `active`, `coming_soon`, `hidden` 상태나 가격은 결제·생성 기능의 실제 제공을 뜻하지 않는다. 따라서 모든 상품이 현재 판매 중이라고 쓰거나 특정 가격을 약관에 고정하지 않았다.
- `../saju-platform/docs/product_context.md`의 기도초 신청 계획을 조건부 조항으로 반영했다. 실제 현장 수행 여부, 수행 기관 또는 제휴 관계는 확인되지 않았으므로 만들어 넣지 않았다.
- 서버의 가입 계약에 있는 만 14세 이상 확인을 반영했다. 특정 외부 로그인 제공자나 이메일 가입을 지원한다고 단정하지 않았다.

## 게시 전에 확정할 내용

1. 통신판매업 신고번호 또는 적법한 면제 여부, 고객센터 전화·이메일, 시행일. 대표자명·등록번호·법인명·사업장 주소는 첨부 사업자등록증을 기준으로 반영했다.
2. 출시 시 실제 제공할 상품과 기도초 포함 여부. 기도초는 온라인 콘텐츠인지 현장 수행인지, 회사가 판매자인지 중개자인지, 수행 주체·시기·완료 증빙·부분 취소 기준이 무엇인지 확정해야 한다. 초안은 회사가 구매자에게 약정한 서비스의 이행 책임을 지는 구성이므로 중개 모델이면 해당 조항을 다시 설계한다.
3. 단건 또는 이용권·묶음 판매 여부, 사용기한, 재열람 기간, 무료 혜택, 부분 환불 계산 방식. 참고 서비스의 3개월 정책을 승인된 우리 정책으로 취급하지 않는다.
4. **제3조의 일반 변경 7일·불리한 변경 30일 사전 안내는 이번 초안의 운영 정책 제안이다.** 현재 회사가 이미 시행 중이라는 의미가 아니다. 개별 안내 수단과 실제 운영 가능 여부를 확인한다.
5. 결제 전 총액·제공 시기·청약철회 제한 안내와 미리보기 등 필요한 조치, 결과 제공 시작 시점, 장애 처리, 환불 접수 경로를 실제 화면과 처리 로직에 맞춘다. 약관 동의만으로 디지털콘텐츠의 법정 청약철회 제한 요건이 모두 충족되는 것으로 구현하지 않는다.
6. 회원 탈퇴, 문의, 공유 공개 범위 안내 및 미성년자 결제 동의 절차를 실제 제공 기능에 맞춘다. 초안의 안내·복구·환불·이의제기 문구는 앞으로 이행해야 할 운영상 약속이다.
7. 개인정보처리방침은 별도로 작성해야 한다. 생년월일시, 타인 프로필, 질문, 기도초 내용, 인공지능 제공자 전달, 위탁·국외 이전 등은 실제 데이터 흐름을 확인한 후 작성한다. 기도초 입력내용의 성격에 따라 민감정보 해당 여부와 필요한 동의도 검토한다.
8. 최종 전문과 약관 버전을 함께 확정한다. 현재 서버는 가입 동의에 `CURRENT_TERMS_VERSION = 'v1'`을 저장하므로, 이미 수집한 동의가 있다면 새 초안을 과거 동의 내용으로 덮어쓰지 않는다. 최종본과 동의 이력의 대응 및 재동의 필요 여부를 확인한다.

## 법령 확인 근거

아래는 문구 작성에 참고한 법령과 공식 안내다. 사업 모델별 법률 검토가 완료되었다는 의미는 아니다.

- 디지털콘텐츠의 청약철회 기간·제한 요건 및 미제공 부분의 권리: [전자상거래법 제17조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=282793&urlMode=lsScJoRltInfoR), [법제처의 청약 관련 의무 안내](https://www.easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=3&cciNo=3&cnpClsNo=3&csmSeq=25&popMenu=ov).
- 적법한 청약철회 후 환급 기한과 결제 취소 요청: [전자상거래법 제18조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0018&lsiSeq=282793&urlMode=lsScJoRltInfoR).
- 소비자 주소지 등을 기준으로 하는 통신판매 거래의 전속관할: [전자상거래법 제36조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0036&lsiSeq=282793&urlMode=lsScJoRltInfoR).
- 미성년자 법률행위의 동의와 취소: [민법 제5조](https://www.law.go.kr/법령/민법/제5조).

## 이번 작업의 범위

약관 전문과 내부 검토 메모, 클라이언트 `/terms` 페이지 및 진입 링크를 작성한다. 서버 코드, API 계약, 동의 버전 및 데이터베이스는 변경하지 않는다. 클라이언트 표시 콘텐츠는 `../saju-platform/src/domains/terms/config/terms_content.ts`에 독립적으로 두며 서버 파일을 런타임에 import하지 않는다. 약관 문구 수정 시 이 전문과 클라이언트 콘텐츠를 함께 갱신한다. 이번 문서는 신규 약관의 실제 시행 또는 과거 동의 내용의 변경을 의미하지 않는다.

## 확인 결과

- 최초 이용약관 페이지 작업에서 클라이언트 `pnpm lint`, 최종 `pnpm build --webpack` 통과. 기본 `pnpm build`는 첫 검증에서는 통과했으나 최종 재실행 시 Turbopack의 CSS 처리용 로컬 포트 생성이 `Operation not permitted`로 차단되어, 설정 변경 없이 공식 Webpack 빌드 옵션으로 검증했다.
- 로컬 `/terms` HTTP 200 응답 확인. 브라우저 상호작용·시각 검사는 수행하지 않았다.
- 17개 조문 순서와 고유 앵커, 84개 항의 문서·표시 데이터 일치 및 타사 사업자 정보가 남지 않은 것을 확인했다.
- 홈 하단과 가입 동의 화면에 진입 링크를 연결했다. 개인정보처리방침 추가 작업에서 두 전문 모두 같은 탭으로 이동하도록 변경했다. 검증된 `returnTo`로 돌아오며 `/terms`, `/privacy`에서는 가입 대화상자를 표시하지 않는다. 두 페이지는 돌아갈 경로의 검색 매개변수를 읽으므로 동적으로 렌더링한다.
- 사업자 표시 정보는 `../saju-platform/src/shared/config/company.ts`로 이동하여 두 전문이 함께 사용한다.
- 약관은 초안 상태로 표시하며 검색엔진 색인을 허용하지 않는다. 시행일 및 운영 조건 확정 시 상태 안내와 메타데이터를 함께 변경한다.
- 서버는 문서만 추가했으므로 서버 lint·unit/e2e test·build 및 migration은 이번 변경의 실행 대상이 아니다.
